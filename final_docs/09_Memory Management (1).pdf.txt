x86 Memory Management
•
 1. Linear Addresses
–
 Paging
•
 By using paging, a computer can run a combination of programs that would not otherwise fit into memory
•
 The processor initially loads only part of a program in memory while keeping the remaining parts on disk
•
 The memory used by the program is divided into small units called 
pages
(typically 4 Kbyte each)
•
 As each program runs, the processor selectively unloads inactive pages from memory and loads other 
pages that are immediately required
•
 The OS maintains a 
page directory
and a set of 
page tables 
to keep track of the pages used by all 
programs currently in memory
•
 Page translation
–
 The conversion from the linear address into a physical address
–
 If the requested page is not currently in memory, the processor interrupts the program and issues a 
page fault
–
 The OS copies the required page from disk into memory before the program can resume
•
 From the point of view of an application program, page faults and page translation happen automatically
