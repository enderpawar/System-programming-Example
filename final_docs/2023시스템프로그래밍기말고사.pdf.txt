답: ______________ 
① MUL 명령은 연산의 결과로써 크기가 2 배 커진 결과값을 생성하므로 Overflow 나 Carry 가 발생할 
수 없고, 해당 flag 들도 1 로 세팅되지 않는다. 
② DIV 명령은 MUL 명령이 수행하는 연산의 역으로 볼 수 있고, dividend(피제수)가 divisor(제수)와 
quotient(몫)보다 2 배 크므로 역시 overflow 가 발생할 수 없다. 
③ 하지만, DIV 명령에서 dividend(피제수)가 0 일 경우, 문제가 발생하므로 DIV 명령을 수행하기 전에 
이를 검사하는 것이 좋다. 
④ MUL 명령은 피연사자를 오직 하나만 갖는데, 상수(immediate value)는 피연산자로 사용될 수 없다. 
⑤ 피연산자를 2 개 또는 3 개 갖는 IMUL 명령을 unsigned 정수에 대해 사용한다면, MUL 연산을 
사용한 결과의 하위 반쪽을 사용하는 것과 동일한 효과를 얻는다.

4. [10pt] 다음은 x86 시스템에서의 메모리 관리에 관한설명이다. 옳지 않은 설명을 모두 고르시오.  
답: ______________ 
① x86 시스템에서 어셈블리어 응용 프로그램을 작성할 때, 동적 메모리 할당이 필요하다면 
운영체제에게 heap 메모리에서의 메모리 블록을 요청할 수 있고, 해당 메모리 블록에 대한 주소를 
반환 받는다. 
② Data 세그먼트상에 존재하는 전역 변수(global variable) 와 달리, 동적 할당된 변수와 지역 변수는 
stack 세그먼트상에 위치한다. 
③ 16 비트 세그먼트 레지스터에 저장된 값과 32 비트 offset 을 결합하여 32 비트 linear address 를 
얻는데, 이는 paging 을 사용하지 않는다면 메모리에서의 physical address 에 해당한다. 
④ 운영체제가 paging 을 사용한다면, linear address 는 page translation 과정을 거쳐 32 비트 physical 
address 로 변환된다. 일반적으로 linear address 보다 physical address 의 address space 가 더 크다. 
⑤ 하나의 page 내에서 서로 연속하여 위치한 메모리 주소는 실제 physical 메모리 내에서도 연속되어 
위치한다.
